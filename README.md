# Komissar

> [!WARNING]
> This project was created for educational purposes and is still under development. It may contain bugs, incomplete features, and architectural flaws. The code is not production-ready and should be used with caution.

A lightweight .NET simulation engine designed for integrating and executing independent systems, tasks, and simulation logic.

Komissar provides a flexible architecture for building simulations and complex applications by composing reusable systems into an execution pipeline.

## Features

- Lightweight and extensible simulation runtime.
- Modular system-based architecture.
- Dependency-aware system execution.
- Sequential and parallel execution support.
- Flexible integration of custom systems and tasks.
- Designed for simulations, games, and other complex applications.

## Core Concepts

- **Simulation Runtime** — manages the simulation lifecycle and execution.
- **Systems** — independent units of logic that process and update the simulation state.
- **System Dependencies** — define execution order and relationships between systems.
- **Execution Pipeline** — organizes systems into executable plans and waves.

## Example Use Cases

- Economic and social simulations.
- Game simulation logic.
- Agent-based systems.
- Complex task orchestration.
- Custom simulation frameworks.
